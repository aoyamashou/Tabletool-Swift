# M1.T2：Reader / Writer 与无损回归

完成标准：冻结接口下实现纯Swift读写；原13个读取用例逐项移植；引号/转义/行尾/空值/不齐列/错误、原始字面/Decimal、Unicode/编码/列序与往返验证；Writer不改输入、不碰文件。已通过tank K017（D026）最终验证，测试24/24。

## 实现

- `Swift/CSVCore/Sources/CSVCore/CSVReader.swift`：Unicode scalar状态机，物理行列错误定位，引用内换行、CRLF/LF/CR、空行、末尾空字段、不齐列。配置冲突、缺引用、非法引用后字符、未知/孤立反斜杠转义明确失败。反斜杠转义只在引用内生效；未引用内容中的反斜杠是字面。
- `CSVWriter.swift`：严格列排列、输出层补空、双写引号/反斜杠、显式小数转换及完整Data返回；不修改输入、不写磁盘。无引用模式无法表达分隔符/换行/单空字段时失败；零字段行明确失败，不私自创造单元格。
- `CSVCodec.swift`：Foundation/CoreFoundation严格编解码及回编码核验；19种枚举编码（旧菜单18项+GB18030）有本机读写回归；BOM与端序显式处理。UTF16LE BOM后NUL与UTF32LE前缀重叠按选定编码家族解决。
- `CSVNumber.swift`：ASCII数值语法和字符串系数/十进制指数规范比较；Decimal只有精确可表达才非nil，不经Double；默认写出只用literal。显式小数转换直接改符合源语法的字面标记，保留超长数字、前导零和指数表示。

`Swift/CSVCore/CONTRACT.md`补充零字段行明确失败这一边界，未破坏公共签名。

## 边界
